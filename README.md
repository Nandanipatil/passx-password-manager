# 🔐 PassX - Password Manager

PassX is a simple password manager web application designed to manage passwords in one place.

## ✨ Features

- 🔐 Password management
- 📋 Copy password
- 🎨 Clean user interface
- ⚡ Lightweight web application

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
